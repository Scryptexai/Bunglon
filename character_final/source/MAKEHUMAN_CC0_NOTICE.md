# MakeHuman base-mesh provenance

`makehuman_base_cc0.obj` is the MakeHuman `base.obj` mesh from the
[makehumancommunity/makehuman](https://github.com/makehumancommunity/makehuman)
repository, revision inspected during Phase 2 on 2026-09-12.

The source file states that it was explicitly released as **CC0** in September 2020;
the upstream `LICENSE.ASSETS.md` contains the CC0 1.0 Universal dedication. The
unmodified upstream copyright notice is retained in the OBJ header.

This file is used only as a CC0 anatomical starting mesh. Lyra Vesper's visual identity,
original costume, head treatment, hair, mantle, weapon, materials, and all project
specific geometry are authored by this project. The production design must not be
represented as an unmodified MakeHuman mannequin.
