# Phase 5 QA — Lyra Vesper Authored Animation Action Set

**Result: Pass — asset-level animation export, deformation, timing, and LOD-parity gate.**

This record applies only to Phase 5's deterministic glTF asset production and offline validation. It does not represent Godot import, `AnimationTree`, runtime event dispatch, gameplay collision, player/AI integration, Android profiling, or final playtest sign-off.

| Quaternion keys | 2,796 | 2,796 |
| Translation channels | 0 | 0 |
| Inverse-bind maximum absolute error | `1.05e-07` | `1.05e-07` |
| Semantic-event socket samples | 41 | 41 |
| Minimum materially moved vertices in one action | 6,458 | 3,699 |
| Highest sampled deformation magnitude | 3.972420 m (`death`) | 3.972420 m (`death`) |

The deformation magnitude is a maximum vertex excursion from the neutral Phase 4 rest mesh during the intentionally in-place death fall; it is not root travel. The validator rejects invalid/unnormalized weights, out-of-palette joints, missing channels, missing clips, malformed events, lost helper parenting, socket discontinuity, unexpected translation channels, and an unsafe sampled displacement beyond its configured 4.5 m guard.
